How to publish this post
  1. Download the post and add it to content/posts/ in your GitHub repository.
  2. If you used a notebook, add it to content/notebooks/. Put figures in assets/images/.
  3. Commit the changes. The included GitHub Actions workflow rebuilds and publishes your site.

Set your repository’s Pages source to GitHub Actions once. This editor creates files locally; it does not sign in to GitHub or publish for you.
